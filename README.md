# GoEvent — Passeios escolares

Projeto acadêmico de Gerência de Projetos: aplicativo para alunos se inscreverem nos passeios de sua escola e organizadores gerenciarem eventos, vagas e participantes.

## Executar

Abra `index.html` em um navegador atualizado. Mantenha os arquivos HTML, CSS, JavaScript e a pasta `assets` juntos. Não há dependências para instalar.

## Recursos

- Cadastro e login de alunos, com seleção da escola Fortec.
- Agenda de passeios com busca, filtros e controle de vagas.
- Painel do organizador com criação e edição de passeios.
- Consulta, remoção de inscritos e exportação CSV.
- Integração com VLibras, que requer internet.

Este é um protótipo local: dados ficam no navegador e os acessos são demonstrativos. Use dados fictícios. Para uma versão em produção, é necessário um servidor com autenticação e autorização.

Consulte [LEIA-ME.md](LEIA-ME.md) para o acesso de demonstração do organizador, o roteiro de apresentação e os limites do protótipo.
